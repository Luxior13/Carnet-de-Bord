# Intentions métier et anciennes spécifications

[Propositions](../README.md) · [Guide général](../../REFERENCE_GENERALE.md)

Ancien dossier `features/` de la racine du dépôt, déplacé ici le 19 octobre 2026
sans modification de contenu hors liens. Les commentaires de migrations SQL
appliquées citent encore les anciens chemins `features/pages/…` ([SYS-05](../../systeme/constats.md)).

Ce dossier conserve les besoins qui ont préparé le produit. Ces textes ne
prouvent ni qu’une fonction est livrée ni qu’une ancienne route doit être créée.
L’état courant vient de la [feuille de route](../feuille-de-route.md),
de la [matrice](pages/MATRICE_PREPARATION.md) et des
[suivis de pages](../../pages/README.md).

Avant de reprendre une intention, identifier ce qui est déjà livré, encore utile,
remplacé ou abandonné. Porter la décision dans son document propriétaire ; éviter
une deuxième liste de tâches dans chaque variante de la spécification. Les
[fiches de pages](pages/README.md) conservent l’ancienne arborescence de conception.
Les [plans](../README.md) contiennent les propositions détaillées.
