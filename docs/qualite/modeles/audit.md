# Audit — titre et date

Supprimer les sections inutiles ; pour une petite retouche, une note dans le suivi
suffit. Appliquer la [méthode d’audit](../AUDITS.md).

## Question, périmètre et état examiné

- Demande et comportement attendu ; source de la décision.
- Type : ciblé, complet sur une page, ou transverse ; routes, API et consommateurs.
- Date, branche/commit, changements locaux, environnement et versions pertinentes.
- Données simulées ou réelles, rôles et appareils effectivement exercés.
- Suivi propriétaire ; exclusions et contrôles empêchés avec leur raison.

## Verdict et suivi

Préciser le périmètre conforme, les corrections nécessaires et les limites qui
empêchent une conclusion complète. Lier les points encore ouverts au suivi
propriétaire, les règles corrigées à leur référence, et le rapport à l’index des
audits. Donner le déclencheur de réexamen pertinent, sans nouvelle échéance inventée.
