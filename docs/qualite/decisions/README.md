# Décisions structurantes

Enregistrer ici uniquement les choix transverses importants : modèle d’identité,
stratégie d’accès, architecture d’exécution, migrations majeures ou mécanisme durable.

Utiliser le [modèle](../modeles/decision.md) avec un identifiant stable
`DEC-001-sujet.md`. Lier la décision depuis les politiques et les pages affectées.
Le statut « proposée » n’autorise pas à traiter le choix comme déjà livré.

Aucune décision supplémentaire n’est créée automatiquement par ce référentiel.
Les décisions actuelles restent dans leurs [documents propriétaires](../REFERENCES.md).
